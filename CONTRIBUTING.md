# Contributing

This organisation follows a shared engineering standard. Read it before opening a pull request or changing process:

**https://github.com/NxtSoft-Solutions/team-dev-standard**

The short version:

1. Every meaningful change starts from a GitHub issue with acceptance criteria.
2. Work happens on an issue-specific branch and arrives by pull request.
3. The pull request links the issue, states what was verified, and is reviewed by the other developer.
4. No secrets, credentials or real customer data in code, commits, logs or AI prompts.
5. Never claim a check passed unless it actually ran.

Repository-specific instructions may tighten these rules; they must not contradict them. Where a repository has its own `CONTRIBUTING.md`, `AGENTS.md` or templates, those take precedence for that repository.
